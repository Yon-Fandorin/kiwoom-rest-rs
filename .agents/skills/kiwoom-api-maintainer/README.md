# Kiwoom API Maintainer

이 저장소의 키움 REST·WebSocket 공개 가이드의 변경을 관찰하고 독립 SDK 계약에 미치는 영향을 판단하는 스킬이다. 문서 변경 감지, 계약 수정과 mock 검증, 실계좌 검증을 서로 다른 증거로 다룬다. 신규·수정·삭제 API 계약과 일반 기능 변경은 루트 변경 이력에 함께 반영한다.

```text
$kiwoom-api-maintainer 현재 저장소의 키움 API 공개 가이드 변경을 점검하고 계약 영향과 미확인 범위를 보고해줘.
```

작업에 맞으면 자동 선택될 수 있다. 구현까지 요청하면 저장소의 경계·호환 경로·금융 변경 차단 정책을 유지하며 수정한다. 키 접근이나 broker 호출, 주기 자동화 생성 권한은 포함하지 않는다.

[SKILL.md](SKILL.md)가 실행 흐름을, [출처 추적 참조](references/source-tracking.md)가 snapshot·diff 명령과 검사 범위를 설명한다. Python 표준 라이브러리만 사용하는 도구를 포함한다. 생성 자료는 이 저장소의 Git 제외 `local/`에 보관한다. 표 밖의 설명·예제·공지와 실제 서버 동작은 도구가 확인하지 않는다.

[릴리즈 문서 참조](references/release-notes.md)는 `CHANGELOG.md`의 `Unreleased` 항목을 중복 없이 갱신하고, 승인된 코드 커밋에 관련 항목이 함께 포함되는지 검사하는 명령을 설명한다. 문서 갱신은 버전 태그·푸시·릴리즈 게시를 실행하지 않는다.
